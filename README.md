# Happy Finance — сайт

Лендинг компанії Happy Finance («Радісні фінанси»): фінансово-бухгалтерський супровід ФОП і ТОВ.

## Структура

- `index.html` — уся сторінка (стилі та скрипт усередині).
- `images/` — фото засновниці, команди та фонове фото.
- `favicon.svg` — іконка вкладки.

## Публікація на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
За 1–2 хвилини сайт буде доступний за адресою `https://<логін>.github.io/<назва-репозиторію>/`.

## Заявки з форми

Зараз форма показує подяку, але нікуди не надсилає дані.
Щоб заявки приходили на пошту, створіть форму на https://formspree.io і вставте її адресу
у змінну `FORM_ENDPOINT` на початку скрипту в `index.html`.
